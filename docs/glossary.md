# 用語集

| 用語 | 意味 |
|------|------|
| 脆弱性（ぜいじゃくせい） | セキュリティ上の弱点・欠陥 |
| PoC (Proof of Concept) | 攻撃が実際に成立することを示す検証手順・コード |
| エスケープ | 特殊な意味を持つ文字を、ただの文字として扱われるよう変換すること |
| プリペアドステートメント | SQLの命令部分と値を分けて送る仕組み。SQLインジェクション対策の基本 |
| サニタイズ / バリデーション | 入力の無害化 / 入力が想定通りの形式か検査すること |
| RCE (Remote Code Execution) | 遠隔からサーバー上で任意のコードを実行できる状態。最も深刻な部類 |
| Webシェル | サーバーに置かれた、ブラウザから命令を実行できる不正なスクリプト |
| Cookie / セッション | ログイン状態を保つ仕組み。盗まれると「なりすまし」される |
| CVE | 公開された脆弱性に付けられる世界共通の識別番号 |
| CVSS | 脆弱性の深刻度を0.0〜10.0で表すスコア |
| CSP (Content-Security-Policy) | ブラウザに実行してよいスクリプトの出所を指示するHTTPヘッダ。XSSの被害軽減に使う |
| OWASP | Webセキュリティの国際的なコミュニティ。Top 10 が有名 |
| 多層防御 | 複数の対策を重ねて、1つが破られても被害を防ぐ考え方 |
