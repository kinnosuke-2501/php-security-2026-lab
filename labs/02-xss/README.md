# 02. XSS（クロスサイトスクリプティング）

## これは何？
ユーザーが入力した内容がそのままWebページに出力され、その中の `<script>` などが
**閲覧した人のブラウザで実行されてしまう** 脆弱性です。
Cookie（セッション情報）の盗難や、偽の入力フォーム表示などに悪用されます。

## なぜ起きる？
脆弱版 `vulnerable.php` は、投稿されたコメントをエスケープせずそのままHTMLに出しています。

```php
echo "<div>{$row['body']}</div>";   // body に <script> が入ると実行される
```

## 対策
- **出力時に `htmlspecialchars()` でエスケープする**（`patched.php` 参照）。
  `<` が `&lt;` に変換され、スクリプトではなくただの文字として表示される。
- テンプレートエンジン（例: Twig/Blade）の自動エスケープを使う。
- 追加防御として Content-Security-Policy ヘッダを設定する。

## 試し方
1. 脆弱版でスクリプトを投稿 → アラートが出る（実行された）
2. 修正版で同じ投稿 → 文字として表示されるだけ
